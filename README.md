# GymTracker Focus — Biblioteka i kreator planów

Zachowano trzy zakładki: Trening, Kalendarz, Progres oraz dotychczasowy zapis danych `gymtracker-iphone14plus`.

## Nowości
- Katalog ze zdjęciami, wyszukiwarką, filtrem grup mięśniowych i szczegółami ćwiczenia.
- Źródło katalogu: [free-exercise-db](https://github.com/yuhonas/free-exercise-db), licencja Unlicense. Zawiera ponad 800 ćwiczeń. Dostęp do internetu jest niezbędny do pierwszego załadowania pełnego katalogu i zdjęć.
- Polski opis obejmuje mięśnie i wskazówkę ogólną, a szczegółowe instrukcje z bazy są wyświetlane w oryginalnym języku angielskim (bez automatycznego tłumaczenia).
- Tworzenie i usuwanie rodzajów treningów; edycja, dodawanie, usuwanie i zmiana kolejności ćwiczeń.
- Historyczne sesje i ich ciężary nie są usuwane wraz z planem.
- Możliwość przywrócenia gotowych planów.
- Uwaga: nie edytuj planu będącego w trakcie wykonywania; aplikacja blokuje tę operację.
